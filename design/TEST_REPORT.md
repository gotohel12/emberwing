## Bugs found and fixed during testing
1. Shader uniform precision mismatch between the vertex and fragment shaders, which would have stopped the game from running on some devices.
2. The page reloaded itself on the first visit because of the service worker (`controllerchange`). It now reloads only when the player presses "Update".
3. After taking off, the bird landed again immediately (takeoff didn't work from a controller).
4. Xbox controllers were detected as PlayStation because both names contain "Wireless Controller".
5. A death loop: after the storm closed in, a checkpoint could end up outside it. Respawning now uses the nearest safe spot.
6. On phones, the pause button and cooldown icons were overlapping other HUD elements.
7. The storm wall looked blocky; it is now a smooth, gradual curtain.

## Not yet verified
- **A real graphics card / real phone:** the test frame rates (~20 FPS at 1280×720) come from software rendering and say nothing about real performance. The game targets 60 FPS on a mid-range device, but that has **not** been measured here.
- **A physical Xbox or PlayStation controller:** tested with simulated controllers using the same browser API. Bluetooth controllers on iPhone and Android depend on the operating system.
- **Real sound:** the audio system was not heard here (headless browser).
- `EMBERWING.exe` was built successfully but has not been run on Windows inside this environment.

## Known limitations
- Graphics are procedural low-poly (generated by code). There are no hand-modeled characters or textures.
- No voice acting. The story is told through text cards.
- Single player only. There is no online mode, and no fake online mode either.
